## 📌 What This Project Does

This is a Git and GitHub practice project that demonstrates essential Git workflows:

- Initializing a repository locally with `git init`
- Making multiple commits with meaningful messages
- Working with branches (`feature/calculator`, `feature/error-handling`)
- Merging branches back into `main`
- Pushing code to a public GitHub repository
- Following a proper folder structure

It includes a simple Python calculator program in `src/` with basic arithmetic operations.
